УЖЕ ЗАГРУЖЕННАЯ МОДЕЛЬ — готовый адрес для поля модели в STUDIO:
https://3xyzmedia.github.io/3xyzmedia-viewer/model/EMELYA%20IN%20THE%20FIRE.ply

Файл на GitHub называется EMELYA IN THE FIRE.ply.
%20 в адресе означает пробел; переименовывать существующий файл не нужно.

ВАЖНО: короткое имя SOY2.ply в Viewer v12 ищется в другом репозитории:
3XyzMedia/3d-models/model/. Для моделей из ЭТОЙ папки используйте полный URL.
Старые модели из 3d-models переносить не нужно.
Не путайте эту папку с v12/model/.
Загрузка в GitHub сама не переключает модель: вставьте URL в STUDIO и загрузите её.

КАК ЗАГРУЗИТЬ:
Add file -> Upload files -> Commit changes. Дождитесь успешной публикации Pages.
В STUDIO вставляйте полный прямой HTTPS-адрес, затем примените/загрузите файл.
Ссылка github.com/.../blob/main/... — страница GitHub, она не подходит.
В адресе пробел заменяется на %20. Регистр букв должен совпадать.
Для новых имён удобнее латиница и подчёркивания без пробелов.
После настройки создайте новую SHARE-ссылку.
