# Карточки ссылок 3XyzMedia

Загружайте сюда два файла из ZIP, созданного кнопкой **VK** в приватной STUDIO FIX24: `scene-….html` и `scene-….jpg`. Сам ZIP загружать не надо. Не переименовывайте файлы: их имена уже записаны в HTML.

После Commit changes дождитесь успешной публикации Pages, откройте ссылку карточки и проверьте переход в Viewer. Затем вставьте ссылку HTML-карточки во VK. Создание ZIP не публикует карточку автоматически.

Каждая новая карточка имеет уникальное имя. Старые файлы нужны для прежних ссылок — не удаляйте их, если хотите сохранить карточки.
